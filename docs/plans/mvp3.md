No new external application dependency was added; the satellite adds only its contracts workspace dependency. Native ALSA tools are an OS installation prerequisite. Provider/HA credentials remain API-only, with a separate satellite environment holding its scoped token. Text/direct controls retain their existing path and persistence.

Stopping capture before submission discards audio. After ChatService accepts a recognized turn, disconnect/playback stop does not cancel or undo execution; the server drains chat and persists the outcome. Clients never automatically resubmit after failure and surface inspection context. Voice identity grants no new permissions.

Exit requires actual browser and satellite deliberate turns plus measured hardware/recovery acceptance. The source and local fixture/container checks are complete; do not present them as physical Pi or live speech validation. Do not start MVP4 implicitly.
